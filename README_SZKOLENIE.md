## 🚀 Jak zacząć?

### Opcja A: Szybki start z Marp CLI
```bash
# Instalacja
npm install -g @marp-team/marp-cli

# Generowanie HTML
marp prezentacja_szkolenie_ai.md -o prezentacja.html

# Generowanie PDF
marp prezentacja_szkolenie_ai.md -o prezentacja.pdf

# Podgląd na żywo
marp -s prezentacja_szkolenie_ai.md
```

### Opcja B: Visual Studio Code
1. Zainstaluj VS Code
2. Zainstaluj rozszerzenie "Marp for VS Code"
3. Otwórz plik prezentacji
4. Używaj podglądu (Ctrl+Shift+V)
5. Eksportuj do wybranego formatu

### Opcja C: Konwersja do PowerPoint/Google Slides
```bash
# PPTX
marp prezentacja_szkolenie_ai.md -o prezentacja.pptx

# Następnie zaimportuj do Google Slides lub otwórz w PowerPoint
```
